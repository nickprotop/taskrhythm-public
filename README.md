# TaskRhythm 

Welcome to the public repository for **TaskRhythm**! 

TaskRhythm is a smart, beautiful, and highly customizable task manager for Android. While the core Android application source code is maintained privately, this repository serves as our public face and community hub.

## What is this repository for?

This repository handles several key parts of the TaskRhythm ecosystem:

1. **Bug Reports & Feature Requests:** We use the GitHub Issue tracker here as the official place for users to report bugs and suggest new ideas. You can even submit these directly from within the TaskRhythm Android app!
2. **Public Roadmap:** Any issue tagged with `enhancement` is automatically synced to a static API (`roadmap.json`) using GitHub Actions. The Android app fetches this file to display a live, natively-rendered roadmap of upcoming features for all users.
3. **Marketing Website:** The `docs/` folder hosts our official landing page via GitHub Pages.
